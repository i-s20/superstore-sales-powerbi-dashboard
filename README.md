# superstore-sales-powerbi-dashboard
![Dashboard](dashboard.png)
Superstore Sales & Profit Dashboard

Project Overview
-An interactive Power BI dashboard built using the Superstore dataset to analyze sales, profit, orders, product categories, regions, and sales trends.

Tools Used
-Power BI
-Power Query
-DAX
-CSV dataset

Key Features
-Total Sales KPI
-Total Profit KPI
-Total Orders KPI
-Profit Margin KPI
-Sales by Category
-Sales by Region
-Sales Trend Over Time
-Profit by Category
-Top 10 Products by Sales
-Interactive filters for Date, Category, and Region

Data Preparation
-The dataset was cleaned and prepared using Power Query. Data types were checked and corrected for dates, numerical fields, and text fields before loading the data into Power BI.

DAX Measures
-The dashboard uses DAX measures for:
Total Sales,
Total Profit,
Total Orders,
Profit Margin

What I Learned
-Through this project, I practiced data cleaning with Power Query, creating DAX measures, designing interactive Power BI dashboards, using slicers and filters, and presenting business insights through visualizations.
